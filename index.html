CONFIGURACIÓN INICIAL

Conecta Firebase para sincronización en la nube y multi-dispositivo. Solo se configura una vez.

1
Ve a console.firebase.google.com y crea un proyecto (sin Google Analytics).
2
En el proyecto → Firestore Database → Crear base de datos → Modo producción.
3
Firestore → pestaña Reglas → reemplaza todo con:
rules_version='2'; service cloud.firestore { match /databases/{database}/documents { match /usuarios/{document=**} { allow read, write: if true; } } }
Sin inicio de sesión: todos los dispositivos comparten la misma ruta de datos. Cualquiera con esta configuración puede leerlos y escribirlos.
4
Configuración del proyecto ⚙️ → Agregar app → Web (</>) → copia el objeto firebaseConfig.
5
Pega el JSON abajo y toca Conectar Firebase.

Modo local: datos guardados en este navegador. No se sincronizan entre dispositivos.
