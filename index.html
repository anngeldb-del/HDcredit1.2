CONFIGURACIÓN INICIAL

Conecta Firebase para sincronización en la nube y multi-dispositivo. Solo se configura una vez.

1
Ve a console.firebase.google.com y crea un proyecto.
2
Agrega una app web (</>), copia el objeto firebaseConfig.
3
En Firestore → Reglas pon: allow read, write: if request.auth != null;
4
En Authentication → Sign-in method, activa Correo/contraseña y crea un usuario.
4
Pega el JSON abajo y haz clic en Conectar.

Modo local: datos guardados en este navegador. No se sincronizan entre dispositivos.
